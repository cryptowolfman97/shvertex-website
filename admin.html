Dropbox Image Workflow
How to add images from your Dropbox:

1. Upload your file to Dropbox (icon, screenshot, etc.)
2. Click Share → Copy Link — you'll get a URL like https://www.dropbox.com/s/abc123/icon.png?dl=0
3. Change ?dl=0 to ?raw=1 at the end of the URL
4. Paste the modified URL into the Icon URL or Screenshot URL fields in the product editor

Result: https://www.dropbox.com/s/abc123/icon.png?raw=1

Store APK Download Link

This single URL powers all download buttons across the site — the homepage, the Store page, and the Products page.
Update it here whenever you release a new version of the SHV Store APK.

Paste your Dropbox direct link here. Make sure it ends with ?dl=1 or ?raw=1 for a direct download.
How this works
The APK URL is stored in your Supabase site_settings table.
All pages load it on startup and apply it to every download button automatically.
If the database is unreachable, a hardcoded fallback URL is used so buttons never break.
